# Cat Lab

Простой сайт о кошках на [Astro](https://astro.build).

## Команды

| Команда           | Действие                              |
| :---------------- | :------------------------------------ |
| `npm install`     | Установить зависимости                |
| `npm run dev`     | Dev-сервер на `localhost:4321`        |
| `npm run build`   | Сборка в `./dist/`                    |
| `npm run preview` | Предпросмотр собранного сайта         |
